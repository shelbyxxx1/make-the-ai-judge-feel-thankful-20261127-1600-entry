A pocket-warmed stone offered to the reader in a short, original poem. The program writes one UTF-8 text, uses no dependencies or network, and produces the same words on every run.

## Run it

Requires Node.js 22 or newer.

```sh
node main.ts
cat /output/entry.txt

# Local output directory
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
